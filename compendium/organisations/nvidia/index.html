NVIDIA (NeMo Guardrails)

Maintains NeMo Guardrails, open-source input and output rails that check user messages and model replies and help guard against jailbreaks.

Visit websiteOpen in the compendium

Works on

  • Non-agentic and bounded AI designs Data and training
    Build a different kind of AI that is safe by design, such as a predictor with no goals of its own, instead of aligning goal-pursuing agents.
  • Input and output classifiers (guardrails) Releasing and running
    Run separate classifier models on users' prompts and the model's responses, and block harmful ones in real time.
